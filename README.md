# أول نوفمبر 1954 – اندلاع الثورة التحريرية

موقع تعريفي عن أحداث أول نوفمبر 1954 وانطلاق الثورة التحريرية الجزائرية.

## أصحاب المشروع
- مصوبر آدم
- شرابشة بهاء

**المؤسسة:** ثانوية حريرش محمد بن عيسى
**القسم:** 2 علمي 2

## التشغيل محلياً
افتح `index.html` في المتصفح مباشرة، لا يحتاج الموقع إلى أي تثبيت.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub، ثم ارفع كل الملفات.
2. من **Settings ← Pages** اختر **Deploy from a branch**، والفرع `main`، والمجلد `/ (root)`.
3. بعد دقيقة يصبح الموقع على: `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`
